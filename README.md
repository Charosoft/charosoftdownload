# 🟠 Charosoft Download

> Télécharge. Simplement.

Charosoft Download est une plateforme web de traitement et de téléchargement
de médias à partir d'URLs, développée par Charosoft.

## 🎯 Vision

Créer une expérience simple, rapide, moderne et accessible permettant à
l'utilisateur d'analyser une URL et de sélectionner les formats disponibles,
dans le respect des droits applicables et des conditions des plateformes
concernées.

## 🧱 Architecture

Le projet est organisé autour de plusieurs composants :

- Frontend : React + Vite + TypeScript
- Backend : Node.js + Express + TypeScript
- Base de données : PostgreSQL
- Traitement média : moteur compatible + FFmpeg
- Application mobile : Flutter (prévue ultérieurement)
